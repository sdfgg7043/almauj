ملفات موقع فواتير شركة الموج

للتشغيل المباشر دون إنترنت أو اشتراك:
1. فك ضغط الملف بالكامل.
2. افتح START.html باستخدام Chrome أو Edge.
3. املأ الفاتورة واستخدم أزرار الطباعة أو تصدير PDF أو PNG.

START.html نسخة مستقلة تضم الشعار والنموذج والتصميم والبرمجة داخل ملف واحد.

للتعديل أو الرفع لاستضافة:
الملفات الأصلية: index.html وstyle.css وapp.js وlogo.png وinvoice.png (كلها في المجلد نفسه).
ارفع هذه الملفات معًا، مع الإبقاء على ترتيبها. لا تحتاج إلى تثبيت مكتبات أو تنفيذ build.

البيانات:
الفواتير محفوظة محليًا في المتصفح ولا تتم مزامنتها بين الأجهزة.
سجل الموقع المنشور لا ينتقل تلقائيًا إلى النسخة المحلية؛ صدّر كل فاتورة مطلوبة بزر حفظ بيانات JSON ثم استوردها هنا.
الحفظ التلقائي للملفات المحلية قد يختلف حسب المتصفح وإعداداته ومكان الملف.
استخدم حفظ بيانات JSON للاحتفاظ بنسخة قابلة للتعديل، وPDF أو PNG للنسخة النهائية.
يدعم النموذج حتى خمسة بنود في صفحة A4 واحدة.
نسخة PDF صورة عالية الدقة وليست نصًا قابلاً للتحرير.
نسخ النص للواتساب يعتمد على إذن الحافظة في المتصفح؛ يمكنك فتح الملفات على استضافة عند الحاجة.

لا تتطلب النسخة المحلية اتصالًا بحساب ChatGPT أو اشتراكًا فيه.
